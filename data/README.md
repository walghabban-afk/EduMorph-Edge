# Data access

The study involved 300 secondary-school students aged 13-18 (University of
Tabuk Local Research Ethics Committee, protocol UT-683-432-2025). The raw
interaction logs (847,320 events) and the engagement-classifier labelling set
(240 students, 14,400 five-minute windows) are therefore not distributed in
identifiable form.

An anonymized version, processed with k-anonymity (k = 5) and differential
privacy (epsilon = 1.2) using the procedures in `anonymize.py`, is available
from the corresponding author on reasonable request, subject to approval by
the ethics committee.

The labelling set is supplied as a single `.npz` file containing the arrays
`student_id` (any integer identifier; remapped to 0..N-1 on loading), `label` (0 = Disengaged, 1 = Transitioning, 2 = Engaged),
`face` (N x 128), `click` (N x 64) and `text` (N x 768). Pass it to the code
with `--data <file>.npz`. Without it, the code runs on the synthetic surrogate
generated by `synthetic_data.py`, which has the same structure but is not a
model of the real data.
